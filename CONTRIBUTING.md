# Contributing

Issues that describe bugs, documentation problems, or focused proposals are welcome through GitHub.

## Licensing of Contributions

Do not submit substantial code contributions unless their licensing has been discussed with the project owner first.

Any accepted contribution must be provided under terms that allow the project owner to continue distributing the project under the public PolyForm Noncommercial license and, when separately agreed, under commercial license terms.

Opening an issue, submitting a pull request, or sending code does not guarantee acceptance.
